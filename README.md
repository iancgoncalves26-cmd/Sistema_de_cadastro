# Sistema de Cadastro de Usuários

Sistema CRUD desenvolvido em Python utilizando SQLAlchemy e MySQL.

## Tecnologias

- Python
- SQLAlchemy
- MySQL
- Pandas

## Funcionalidades

- Cadastro de usuários
- Listagem de usuários
- Busca por email
- Remoção de usuários
- Validação dos dados

## Estrutura

projeto/;
├──painel/;
    ├──Buscar.py;
    ├──cadastrar.py;
    ├──Listar.py;
    ├──painel.py;
    ├──Remover.py;
├── __main__.py;
├── connect_sql.py;
├── dd_filter.py;
└── README.md;

## Como executar

1. Instale as dependências
2. Configure o banco MySQL
3. Configure as variáveis de ambiente
4. Execute:

python main.py
